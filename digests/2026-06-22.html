The Confirmation Issue — 造模型的人自己承认:模型已不再是产品

本期一句话 · TL;DR

今天这批 Latent.Space 积压里有一条压倒性主线:Vol.018『装置才是车』的论点,这次不是旁观者推断,而是造模型的人亲口确认。gdb 直说『模型本身已不再是产品』,AI21 关停模型团队转做 agent,连 DeepSeek 都首次组建 Harness 团队;Fiona Fung 把『不可训练的角落』讲清楚——安排私有现实、把工具递到模型手里、改变客户的工作方式,这些训不进权重,而 intent 比算力还稀缺;OpenAI 干脆下线微调 API,把 80% 的人推向长提示,只剩 top 1% 还在加码开源 RLFT。三篇互不相约,却共同给上一卷盖章。

带着这 3 个问题读 · 思考题

  1. 当 gdb 这种『大模型至上』阵营的人都改口说『模型本身已不再是产品』,你的产品规划里,是不是还在押注『换个更强的模型就能赢』?
  2. 如果『不可训练的角落』——安排私有现实、递工具、改变客户工作方式——才是真正难复制的那层,那你团队里有多少人在做这件训不进权重的脏活累活?
  3. OpenAI 下线微调、把 80% 的人推向长提示,而 Cursor/Cognition 反而加码开源 RLFT——你属于 top 1% 还是 bottom 99%?这个判断会决定你该用哪套技术栈。

▎ 深度分析 · 2 篇

LATENT.SPACE · 行业拐点

造模型的人改口了:模型本身已不再是产品

Latent Space AINews(gdb / dzhng 等) · 原文
信号 ●● · 颠覆 ●● · 可操作 ●● · 独特 ●○ · 时效 ●● · 9/10
在 OpenAI 可能下周递交 IPO 文件的前夕,gdb 直白说出『模型本身已不再是产品』——这是『大模型至上』阵营的一次集体反转;模型公司正一个接一个把 agent 当成产品,模型沦为其中一个被协同训练的部件。
承重论据 · 为什么成立

反转来自阵营内部,而不是外部批评者。

说『model alone is no longer the product』的是 gdb,曾几乎所有 Team Big Model 的人都持相反立场;dzhng 进一步说顶级产品需要 model<>harness<>product 的共生。当『一切靠模型』的人自己改口,这就不再是观点之争,而是行业承认了产品面在向上层(harness + workflow + UI + memory + economics)迁移。

组织结构在跟着改:模型团队关停,Harness 团队新建。

AI21 关掉模型团队,整体转向 agent;连一向以纯模型著称的 DeepSeek 都第一次组建『Harness 团队』。组织架构是最诚实的信号——公司把人和预算投到哪,哪里才是它真正认定的产品。模型不再是终点,而是要被装进 harness 才能卖。

协同训练 model+harness,反而可能让模型更封闭。

『系统派』会把这当成胜利,但有个反噬:如果你能把模型 posttrain 到只在自家闭源 agent 里才好用,你就能把绝大多数用户导流到 agent、牺牲掉模型/API 的开放。装置赢了,代价可能是模型访问被进一步关死——这是开发者要警惕的下一步。

一个张力 · 它没说的
这条主线有个张力:harness 研究本身正在收敛成『复刻 Claude Code』(teortaxesTex 的担忧),而不是去探索更广的交互形态。也就是说,大家都意识到装置重要,却一窝蜂去抄同一套装置——真正稀缺的不是『做 harness』,而是『做一个别人没想到的 harness』。装置是新战场,但同质化的装置和同质化的模型一样不值钱。
对 TikTok Gaming 意味着什么
对 TikTok Gaming 的意义是:不要把『换更强的模型』当成产品路线图的主轴。模型公司自己都承认模型会同质化,那游戏侧真正该当作核心资产经营的,是模型周围那套别人搬不走的装置——玩家行为数据闭环、匹配/推荐/数值/反外挂的系统协同、把模型接进真实流量做高频实验的 harness。具体动作:盘点现有 AI 能力栈,区分哪些是『买得到的模型』、哪些是『只有我们有的装置』,把研发重心从追模型版本号挪到加厚装置上;同时警惕供应商的封闭化倾向,凡是核心场景都保留模型可移植性,别被 posttrain 锁进某一家的闭源 agent。
值得记住的原话

“the model alone is no longer the product”

模型本身已不再是产品。

“models cotrained with harnesses does open the door for closing access to models even further.”

与 harness 协同训练的模型,反而为进一步关闭模型访问打开了门。

LATENT.SPACE · 不可训练的角落

训不进权重的那层,才是真正的护城河

Latent Space AINews(Fiona Fung / swyx 转述) · 原文
信号 ●● · 颠覆 ●● · 可操作 ●● · 独特 ●● · 时效 ●○ · 8/10
Fiona Fung 用『可读性(legibility)』框架把上一卷的装置论讲到了底层:能被复制的终将被训进模型,真正的护城河是『不可训练的角落』——安排私有现实、把工具递到模型手里、改变客户的工作方式;而最稀缺的输入不是算力,是 intent(选择该做什么)。
承重论据 · 为什么成立

『不可训练的角落』靠的是不光鲜的脏活,且永不结束。

应用赢得这块地的方式,是 unglamorous work:把一家公司的私有现实整理成模型能行动的形态、把工具递到模型手里、和客户一起改变其工作方式。带来这种『翻译』的公司极难被抄,因为翻译永不结束——集成与维护和客户关系一样长,靠的是把领域专精的工程师和工具放到客户身边。这正是模型同质化也吃不掉的那层。

今年最被引用的 benchmark 分数,是一张『即将作废』的地图。

Anthropic 之所以急着用 FrontierCode 做 Fable 发布,正因为可验证的免费 benchmark 一旦人人刷满就失去区分度——『最被引用的分数,是一张即将作废的领土地图,也是一份通知:谁即将失去定义什么算好的资格』。把竞争力寄托在公开榜单上的人,正在被这条规律淘汰。

intent 可能是比算力更稀缺的输入。

Fung 说真正难的是 offense——首先选择该做什么。模型在这件事上帮不上忙:你指哪它打哪,但它没法告诉你什么值得指,而这也无法 benchmark、无法训练。这也解释了为什么在位者吃不下全部——下一个东西总来自某个先于众人找到用途的人。能力可买,但『指向哪里』买不到。

一个张力 · 它没说的
这套框架的张力在于它很难被『努力』直接攻克:Fung 自己说一年只找到大概三次值得做的方向。也就是说,『不可训练的角落』不是一个可以堆人头、堆 GPU 就能填上的工程任务,而是依赖判断力和对真实场景的深入——这恰恰是组织最难规模化、最难考核的东西。承认 intent 稀缺容易,把公司组织成『能持续产出好 intent』很难。
对 TikTok Gaming 意味着什么
对 TikTok Gaming 的意义是把投入从『可训练』挪向『不可训练』。可训练的部分(更强的模型、更高的榜单分)会被整个行业同步追平,押注它等于押注一个必然贬值的资产;真正该加厚的是不可训练的角落——只有我们掌握的玩家私有现实(行为、社交图、消费链路)、把这些整理成模型可行动形态的数据工程、以及和真实业务一起迭代的领域专精团队。落地两步:一是停止用公开 benchmark 当内部 AI 能力的主要 KPI,改用贴近真实业务的私有评测;二是有意识地经营 intent——把『该做什么』当成稀缺资源,保护那些能持续找到新用途的人和小团队,而不是只奖励能把已知指标做得更高的人。
值得记住的原话

“An application earns its place in the untrainable corner by doing unglamorous work.”

应用赢得『不可训练角落』的方式,是去做那些不光鲜的脏活。

“Maybe intent is an even scarcer input than compute.”

也许 intent(选择该做什么)是比算力更稀缺的输入。
