EDITORIAL · 编辑卷首语

今天是个『瘦身日』——24 小时窗口只入库 5 条,没有往日 takara.ai 的 arxiv 洪流。但少不等于淡:今天最响的信号,是一张图引发的全网集体误读。Citadel 的『tokconomics』报告配上 Silicon Data 的『LLM token 支出指数』掉头向下,被社交媒体疯传成『AI 需求崩了、泡沫要破、agentic 热潮退回原点』。AI Daily Brief 的 NLW 把这张图逐帧拆开,结论很冷静也很关键:这张图跟 token 需求无关、跟 token 总量无关、也跟实际总支出无关——它量的只是『第三方 token 路由器上每百万 token 的加权均价』。而人们用路由器恰恰是为了省钱、把请求导向更便宜的模型,所以这个指数天生就会夸大『市场正在逃离前沿模型』的程度。一句话:这就像只统计折扣店的客单价,然后宣布全国消费降级。

把误读拨正之后,真正的结构性信号才浮出来,也就是本卷的标题——token 正从『补贴时代(廉价管够)』走向『配给时代(为效率付费)』。NLW 的判断很直接:每一家 AI 公司现在都进入了『token 效率』生意,因为从辅助式到 agentic 用法的迁移,把单个任务的 token 消耗放大了几个数量级,而 token 在物理上是有限的。但这绝不等于需求见顶——他甩出的量级对比把泡沫论按在地上:头部 1% 完全 AI 化的公司已经花到每人每月 7.5 万美元,而中位公司只花 11.38 美元,中间隔着约 6600 倍。换句话说,渗透才刚刚开始,总需求的增长会极大压过『转向廉价 token』带来的均价下移。连 Citadel 报告自己的真实结论都远没那么耸动:最贵的前沿 AI 会向『最能用好它的一小撮公司』集中——这不是泡沫破裂,这是市场在理性化地配置稀缺资源。

这条主线和近几卷严丝合缝:Vol.013 说底层智能正被商品化、稀缺的是把它编排进你独有循环的能力;本卷补上经济侧的另一半——当 token 进入配给,胜负手不再是『谁买得起最贵的 token』,而是『谁有领域深度把难题的回报规模化』。配套两条 brief 也都在这条线上:本周 GitHub 被 Agent 生态霸榜,其中 headroom 这类『喂 LLM 前压缩上下文省 60–95% token』的工具,正是把『token 效率』从理念变成可立刻装的依赖;Lenny 社区则在追问『AI 到底怎么改变了产品运营模式』——这是 Vol.013『人从写 prompt 上移到设计循环』在组织层面的回声。5 条候选全部析出精读(1 deep / 2 brief / 2 skim / 1 dup,Fable 5『被政府叫停』因无字幕降级追踪),新增 7 条观点入库。一句话收口:别被一根吓人的线带节奏——先问它到底量的是什么;真正的故事不是泡沫,而是稀缺,而稀缺时代奖励的是会把前沿用在刀刃上的人。

论点 01

"The speed at which the investors have gone from token maxing to token panic is head spinning. And yet the chart in question... shockingly doesn't say what everyone on social media is saying it says. This chart, which shows a big scary downward line on something called the token expenditure index, has nothing to do with token demand, nothing to do with token volume, and nothing to do with actual token expenditure."
「投资者从『token 管够(token maxing)』切换到『token 恐慌(token panic)』的速度快得令人眩晕。然而那张被议论的图……令人震惊地根本不是社交媒体上所有人所说的意思。这张在所谓『token 支出指数』上显示一根吓人下行线的图,跟 token 需求无关、跟 token 总量无关、也跟实际 token 总支出无关。」
MIRA · 批注
MIRA · 批注:这是本卷的定盘星,也是一堂顶级的『数据素养』示范课。一张图被病毒式误读,核心错误是把『均价指数』当成了『需求/总量/总支出』。NLW 的方法值得逐条学:① 回到数据源方(Silicon Data)看官方澄清;② 追问数据采自哪里(只采第三方路由器);③ 据此判断它会系统性高估什么(高估『逃离前沿模型』的程度)。给 Gaming 的直接价值:你们每天都在被各种『AI 看板/留存图/付费曲线』推着做决策,这集给了一个可复用的反误读 checklist——任何一根『吓人的线』先问三件事:这指标到底量的是什么?数据采样来自哪个口径?这个口径会系统性放大或缩小什么?把它做成团队看数据的肌肉记忆。

论点 02

Silicon Data's own clarification: "Our LLM token expenditure index should really have been named the token expenditure price index because it's an expenditure or usage weighted average token price index. It tells you how much currently the entire market AI is paying for a million LLM tokens, irrespective of models." The index draws only from third-party token routers — whose entire purpose is to route to lower-cost models.
Silicon Data 官方澄清:「我们的『LLM token 支出指数』其实应该叫『token 支出价格指数』,因为它是一个按支出/用量加权的 token 均价指数,告诉你当前整个市场为一百万 LLM token 付多少钱,与具体模型无关。」而该指数只采自第三方 token 路由器——而路由器的全部存在意义,就是把请求导向更低成本的模型。
MIRA · 批注
MIRA · 批注:这条是证伪的技术核心,妙在『数据来源决定了结论的偏差方向』。指数只采自路由器,而人们用路由器恰恰是为了省钱、把请求导向更便宜的模型——所以这个指数天然会夸大『市场正在逃离昂贵前沿模型』的程度。这就像『只统计折扣店的平均客单价,然后宣布全国消费降级』。给 Gaming 的方法论:做任何内部指标前,先画清楚『采样总体 vs 你想推断的总体』之间的缺口。比如只用『主动反馈用户』推断全体玩家满意度、只用『核心公会』推断版本口碑,都会犯同类系统性偏差。建立指标时强制标注采样口径与已知偏差方向,是低成本高回报的治理动作。

论点 03

"I think every AI company is now in the token efficiency business. The equation is really simple. The shift from assisted to agentic use cases radically increases the amount of AI that companies use. Because of the real constraints of the physical world, there are only so many tokens to go around. As demand starts to outpace supply, the prices that people pay get high and companies which never had to think about token efficiency... now all of a sudden do."
「我认为现在每一家 AI 公司都进入了『token 效率』生意。等式很简单:从『辅助式』到『代理式(agentic)』用例的迁移,极大增加了公司用掉的 AI 量。由于物理世界的真实约束,token 总归是有限的。当需求开始超过供给,人们付的价格就会上升,那些从前根本不用考虑 token 效率的公司……现在突然都得考虑了。」
MIRA · 批注
MIRA · 批注:这是把误读拨正后真正的结构性信号,也是本卷标题『token 稀缺』的由来。它和 Vol.013『智能商品化』、Vol.011 Jensen『AI 工厂/按量付费』连成一条经济主线:agentic 用法把单任务的 token 消耗放大几个数量级,补贴时代(廉价管够)正在让位于配给时代(要为效率付费)。给 Gaming 的务实动作:凡是要规模化跑 agent 的场景(批量素材、QA、客服、数据处理),从第一天就把『token 效率』当一等约束来设计——分层用模(便宜模型做粗活、前沿模型做难活)、缓存与复用中间结果、压缩喂给模型的上下文(呼应 Vol.013 headroom 那类工具)。别等收到账单才补效率课。

论点 04

"Right now the top 1% of firms — those who are fully AI'd — are spending about $75,000 per employee on AI... But when you move down to the top 10%, that number comes all the way down to $610 per month... and the median firm... AI spend sits at $11.38. When the median company is still only spending 11 bucks a person on AI, the sheer amount of growth in total AI that will be consumed... massively outweighs any shift away from the most expensive tokens."
「现在头部 1% 的公司(完全 AI 化的)每名员工花约 7.5 万美元在 AI 上……但下移到头部 10%,这个数字一路降到每月 610 美元……而中位公司……AI 支出仅为 11.38 美元。当中位公司每人每月还只花 11 块钱在 AI 上,未来被消费掉的 AI 总量的增长……会极大地压过『从最贵 token 转向较便宜 token』这种结构变化。」
MIRA · 批注
MIRA · 批注:这条用一个量级对比,把『泡沫论』按在地上——头部与中位之间是 75000 vs 11.38 的鸿沟(约 6600 倍)。它的含义不是『泡沫』,而是『渗透才刚开始』:绝大多数公司离『需要设上限』的成熟度还差得远,总需求的增长空间被严重低估。给 Gaming 的战略判断:不要被『大厂开始设 token 上限』的新闻吓到而误判 AI 投入见顶——那是头部 1% 的烦恼。对绝大多数团队,真实状态是渗透率与人均强度都极低,增量空间巨大。当下该做的是提高『有效采纳强度』(人均真正用起来),而不是过早收紧预算。把 AI 投入节奏对标自己的成熟度阶段,而不是对标头部 1% 的账单焦虑。

论点 05

Citadel's actual (less bombastic) point: "We do not think this implies that the frontier of inference intensive AI will be abandoned, only that it is likely to be concentrated among a narrower set of firms with the balance sheets to absorb the compute costs, the research depth to deploy it effectively, and most important, the operating domain to scale the rewards from solving genuinely hard problems." NLW: "That's not an AI bubble popping. That's an AI market rationalizing."
Citadel 报告的真实(远没那么耸动的)观点:「我们并不认为这意味着推理密集型 AI 的前沿会被放弃,只是它很可能会集中到一小撮公司手里——那些有资产负债表去吸收算力成本、有研究深度去有效部署、且最重要的是有经营领域去把『解决真正难题』的回报规模化的公司。」NLW 总结:「这不是 AI 泡沫破裂,这是 AI 市场在理性化。」
MIRA · 批注
MIRA · 批注:把这条放在收尾,是因为它给出了『稀缺时代』的资源配置图景——最贵的前沿 AI 会向『最能用好它的人』集中,这是市场在高效配置稀缺资源,不是需求崩盘。它和 Vol.012『把判断/意图留给人』、Vol.013『稀缺的是编排能力』形成闭环:当前沿算力稀缺,胜出的不是『谁能买到最贵的 token』,而是『谁有领域深度把难题的回报规模化』。给 Gaming 的组织含义:前沿模型预算应向『能把它转化为可规模化回报的高杠杆场景与团队』集中,而非平均撒给所有人;同时在长尾场景用便宜模型保证广覆盖。一句话:前沿 token 集中投给会用的人,长尾用廉价模型铺面——这就是 token 配给时代的内部分配原则。

TIKTOK GAMING · TAKE-HOME

  1. 建立『反误读 checklist』当看数据的肌肉记忆:任何一根吓人的线先问三件事——这指标到底量的是什么、数据采样来自哪个口径、这个口径会系统性放大/缩小什么(本集 NLW 拆图法可直接抄)。
  2. 做内部指标时强制标注『采样总体 vs 推断总体』的缺口与已知偏差方向:别用主动反馈用户推断全体满意度、别用核心公会推断版本口碑——这类系统性偏差和『只采路由器推断全市场』同源。
  3. 凡规模化跑 agent 的场景从第一天就把 token 效率当一等约束:分层用模(便宜模型做粗活/前沿做难活)+ 缓存复用中间结果 + 压缩上下文——补贴时代结束,别等账单来才补效率课。
  4. 别被『大厂设 token 上限』吓到误判 AI 投入见顶:那是头部 1%(7.5 万/人)的烦恼,中位公司仅 11.38/人——对多数团队当务之急是提高人均有效采纳强度,把投入节奏对标自身成熟度而非头部账单焦虑。
  5. 按『token 配给时代』分配模型预算:前沿 token 集中投给能把难题回报规模化的高杠杆场景与团队,长尾场景用廉价模型铺面——前沿向会用的人集中,是市场理性化不是泡沫。
