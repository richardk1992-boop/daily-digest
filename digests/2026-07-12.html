Beyond the Model — 当模型沉为公用事业,价值逃向两端

本期一句话 · TL;DR

同一天两件事对撞:GPT-5.6 甩出 3 模型 × 多档 effort 共 36 个变体、成本模型不透明到 OpenAI 两次重置用量;而 OpenAI 被传向美国政府让渡 5% 股权。模型正从『最强资产』沉为可被持股、被监管、被卡发布节奏的公用事业。价值随之逃向两端:机器侧是套在模型外的 harness(路由/记忆/工具/护栏),人侧是判断、品味与克制。而 swyx 泼了冷水——RSI 只在已知分布里打转,数据效率才是真正的墙。

带着这 3 个问题读 · 思考题

  1. 如果你依赖的前沿模型明天被政府以『关键基础设施』名义卡住发布节奏或改变可用性,你的业务有没有一条不依赖单一实验室的降级路径?这个风险在你的架构里被定价了吗?
  2. 当竞争从模型转移到 harness,而 harness 本身也在被开源快速复制(Deep Agents / OpenSWE),你真正不可复制的到底是编排能力,还是喂给它的私有上下文与交互闭环?
  3. 面对『Sol Ultra 一小时用 64 个 subagent 证明猜想』这类叙事,你如何区分『能力表演』与『范式突破』?你的长期路线是在等下一个基座,还是在积累别人拿不到的专有数据?

▎ 深度分析 · 2 篇

LATENT SPACE · harness 竞争

模型趋同之后:真正的产品是套在模型外面的 harness

AINews (Latent Space) · 原文
信号 ●● · 颠覆 ●○ · 可操作 ●● · 独特 ●○ · 时效 ●● · 8/10
前沿模型能力正在收窄趋同,竞争重心从『模型本身』转移到套在模型外面的 harness——路由、记忆、工具调用、安全护栏与企业上下文;但 harness 自己也在被开源快速复制,真正稀缺的可能是喂给它的私有上下文。
承重论据 · 为什么成立

『真正的产品现在是 harness』正从一句金句变成行业结构。

Perplexity 的 Arav Srinivas 直言 the real product is now the harness around it;LangChain 用 Deep Agents + Nemotron + OpenShell 定位,OpenWiki / OpenSWE 等 memory/orchestration 工具集中冒头。当前沿模型 parity 收窄,价值就系统性地转向路由、记忆、工具使用、安全护栏和企业上下文——这不是个别产品选择,而是一整周的行业信号。

GPT-5.6 的『36 变体 + 隐藏成本爆炸』证明:模型层的复杂度正在外溢成 harness 层的必答题。

API 用户面对 3 模型 × 多档 effort 共 36 个组合,社区被迫写指南(『从比 5.5 更低的档位起步』);更棘手的是 subagent 成本爆炸——spawn_agent 不让选模型/effort,Sol Ultra 默认再 spawn Sol Ultra,配额被悄悄烧穿。OpenAI 两次重置用量、承认默认值把用户推向过贵设置。选模型、控 effort、限制 subagent 扇出——这些本质都是 harness 要解决的问题。

能力增量正从『纯 chat 质量』转向『编排与 computer use』。

多位用户指出 GPT-5.6 最大的感知跃迁是 Sol 作为 planner/verifier/orchestrator 异常强,会自动调度 subagent、对 steering 反应更快;OpenAI 演示 Sol Ultra 的 computer use、把 ChatGPT Work 定位成把 agent 带到消费级规模。价值不在模型多聪明,而在它能多好地被编排、被纠偏、被安全地放进真实工作流——这正是 harness 的定义域。

一个张力 · 它没说的
这条护城河的软肋是:harness 本身正在被开源快速复制。Deep Agents、OpenSWE、OpenWiki 都是开放的,memory/orchestration 的最佳实践几个月就会扩散——今天的『harness 优势』很可能是下一个被商品化的层,就像模型能力这一年被商品化一样。如果 harness 也趋同,真正不可复制的就退回到两样东西:喂给 harness 的私有上下文/专有数据,以及对自己业务『模型为什么这么答』的理解深度。把 harness 当终点护城河可能过于乐观,它更像是暂时领先、需要不断用私有数据加固的阵地。
对 TikTok Gaming 意味着什么
对 TikTok Gaming 而言,这条主线的可操作版本是『别把钱押在模型选型上,押在 harness + 私有上下文的闭环上』。推荐、反作弊、内容安全、玩家分层这些能力,底层模型半年就会被市场追平;真正难复制的是围绕它们的编排层——如何路由不同规模的模型控成本、如何把玩家行为/风控信号作为记忆喂进去、如何设置安全护栏防止 subagent 成本失控。GPT-5.6 的 36 变体和 subagent 成本爆炸是一个直接警告:任何接入多档模型的链路都必须在 harness 层显式管住『默认档位』和『subagent 扇出』,否则配额会被悄悄烧穿。而当 harness 的最佳实践被开源扩散,能守住的只有喂进去的专有数据——这恰是 TikTok 体量下最该被珍视的资产。
值得记住的原话

“The real product is now the harness around it.”

现在真正的产品,是套在模型外面的那层 harness。

“frontier model parity is tightening, so value is increasingly shifting to routing, memory, tool use, safety rails, and enterprise context.”

前沿模型正在趋同,价值因此不断转向路由、记忆、工具使用、安全护栏和企业上下文。

LATENT SPACE · 主权与范式

当模型被政府持股:沉为公用事业,而 RSI 撞上数据效率的墙

Latent Space × Matthew Berman(swyx 对谈) · 原文
信号 ●● · 颠覆 ●● · 可操作 ●○ · 独特 ●● · 时效 ●● · 9/10
前沿模型正被当作国家关键基础设施来持股与监管(传闻 OpenAI 向美国政府让渡 5% 股权),模型本身沉为公用事业;与此同时 swyx 泼冷水——LLM 驱动的递归自我改进只在已知分布里打转,真正的墙是数据效率,不是算力。
承重论据 · 为什么成立

『政府持股前沿实验室』说得通,因为诞生了前沿智能却不分享 upside 会制造永久底层。

swyx 以新加坡为类比:淡马锡/GIC 持有关键企业的显著股份、国民养老金与保险投资于国家关键公司,运作良好。他认为任何国家若创造了前沿智能,公众都需要在其成功中有一份 stake 或话语权,否则会产生永久底层与严重社会动荡。同时他观察到政府近几周已在实质决定哪些模型公开、发布时机(GPT-5.6 宣布后被卡几周才发)——模型正被当作需要被持股和调控的公用事业。

LLM 能 enable RSI,但递归的边界≈现有知识分布,真正的 unknown unknowns 仍属研究领域。

swyx 判断 RSI 确实在『recursing』,但它探索的东西大多已被探索过,离现有知识分布不远;发现真正的 unknown unknowns、构建真实世界模型仍需『别的东西』。他甚至预期 Fable 会是『这一代 LLM 的终点』。这直接给『模型自己造出下一代直到 AGI』的叙事设了上限——同一周 Sol Ultra 号称一小时用 64 subagent 证明猜想,恰是需要被冷静区分的『能力表演』。

用人类类比机器是 sour lesson;真正的墙是数据效率,方向是把 2000 个 example 降到 20 个、2 个。

swyx 认为机器可以是一种 alien 的、与人类完全不同的更高效学习形态,不必套进『人类怎么学』的框。但当前 LLM 在数万亿 token 上学习才逼近人类劳动,而人类在百万量级 example 上就能做有用的事——这种低效是『unmitigated negative』。把样本效率提升几个数量级,才能支撑 continual learning 与真正的 world model,否则始终困在 pre-train/post-train 范式的天花板下。

一个张力 · 它没说的
两条线都带『如果/预测』成分:5% 股权是未证实的传闻,Fable-是-终点、RSI-撞墙也是 swyx 的个人判断,不是既成事实。把它们当定论会有把观点当数据的风险。但价值不在预测准确,而在压力测试——它逼你回答两个现在就该有答案的问题:『假如我依赖的模型被以国家安全名义卡住发布/改变可用性,我怎么办』,以及『假如下一个基座并不会很快到来,我的增量该从哪来』。无论传闻是否落地、swyx 是否说对,这两个问题都值得现在就想清楚。
对 TikTok Gaming 意味着什么
对 TikTok Gaming 而言,这两条线合起来是一个务实的对冲提醒。其一,作为横跨多地缘、直接受主权与合规约束的公司,把关键能力单押在某个特定地区的闭源前沿上,是会被政治变量放大的单点风险——需要一条『可持有、可自训、可在本地区合规运行』且被真实演练过的降级路径,这与 Vol.038『主权护城河』一脉相承。其二,swyx 的『RSI 撞墙、数据效率才是墙』提醒:不要把长期路线押在『等下一个更强基座自动解决问题』上。TikTok 体量下真正的增量来自你喂给系统的专有数据与交互闭环——玩家行为、风控信号、运营反馈——把这些做成高样本效率的持续学习闭环,比追逐每一个新模型更接近可持续优势。
值得记住的原话

“the people of any country where such frontier intelligence is created do need to have a share or a say in some upside, otherwise you have a permanent underclass.”

任何诞生了前沿智能的国家,其国民都需要在这份 upside 里有股份或话语权,否则就会出现一个永久底层。

“Every time you try to make a human analogy to machines, you probably fail.”

每次你想用人类来类比机器,大概率都会失败。
